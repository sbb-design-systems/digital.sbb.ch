## States

The component has the following states:

- Default
- Hover
- Pressed
- Expanded (List variant only)

## Variants

The component has the following variants:

- Mode: light/dark
- Size: default/small
- Type: Toggle/List

### Toggle

When an app offers two layers, users switch between them by selecting the button.

### List

Selecting the button opens the layer list. Users can choose a layer by selecting it or navigating with the Tab or arrow keys. The list closes and the map layer changes after a selection.
