## What does the component do?
A badge is a small marker attached to an element, for example an icon. It shows brief information such as a count and draws attention to new items or changes.

## When should the component be used?
* To indicate a count, for example changed filters or unread messages.
* To draw attention to a change on an icon or button.

## Rules.
* A badge should contain only a few characters, usually a short number.
* A badge is mainly placed on an icon.
* The meaning of the badge must also be available to screen readers, for example via an `aria-label` on the element.
