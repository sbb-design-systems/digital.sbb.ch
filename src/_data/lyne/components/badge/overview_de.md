## Was macht die Komponente?
Ein Badge ist eine kleine Markierung an einem Element, zum Beispiel an einem Icon. Es zeigt eine kurze Information wie eine Anzahl und macht auf Neues oder Veränderungen aufmerksam.

## Wann soll die Komponente eingesetzt werden?
* Um auf eine Anzahl hinzuweisen, zum Beispiel geänderte Filter oder ungelesene Nachrichten.
* Um auf einem Icon oder Button auf eine Veränderung aufmerksam zu machen.
