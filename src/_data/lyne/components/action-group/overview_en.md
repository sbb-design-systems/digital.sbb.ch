## What does the component do?
An action group arranges [buttons](/en/design-system/lyne/components/button/) and [links](/en/design-system/lyne/components/link/) together. This bundles related actions and displays them consistently.

## When should the component be used?
* To display several related actions compactly and clearly.
* To group related actions for user guidance.

## Rules.
* The order is logical: actions that continue the process are on the right. Actions like "Back" or "Cancel" are on the left.
* There is only one primary button.
* Buttons and block links are allowed in all variants.
* On small screens, the elements can be stacked and displayed at full width.
