
## What does the component do?
The selection action panel combines a [checkbox panel](/en/design-system/lyne/components/checkbox-panel/) or a [radio button panel](/en/design-system/lyne/components/radio-button-panel/) with an action, e.g. a button. Users can select an option and directly trigger a related action.

## When should the component be used?
* When an option has its own action, e.g. showing details or editing the option.
* When options and actions are to be displayed together in a list.

## Rules.
* Selection action panels are used inside a [checkbox group](/en/design-system/lyne/components/checkbox-group/) or [radio button group](/en/design-system/lyne/components/radio-button-group/).
* Each panel has exactly one action. It must be clearly distinguishable from selecting the option.
* The action should have a clear label. An icon-only button needs a label for screen readers.
* If additional content should expand, combine the selection action panel with the [selection expansion panel](/en/design-system/lyne/components/selection-expansion-panel/).
