
## Was macht die Komponente?
Das Selection-Action-Panel verbindet ein [Checkbox-Panel](/de/design-system/lyne/components/checkbox-panel/) oder ein [Radio-Button-Panel](/de/design-system/lyne/components/radio-button-panel/) mit einer Aktion, z.B. einem Button. So können Nutzende eine Option auswählen und direkt eine zugehörige Aktion auslösen.

## Wann soll die Komponente eingesetzt werden?
* Wenn zu einer Option eine eigene Aktion gehört, z.B. Details anzeigen oder die Option bearbeiten.
* Wenn Optionen und Aktionen in einer Liste zusammen dargestellt werden sollen.
