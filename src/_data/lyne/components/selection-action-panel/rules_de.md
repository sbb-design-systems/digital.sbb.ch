## Regeln.
* Selection-Action-Panels werden innerhalb einer [Checkbox-Group](/de/design-system/lyne/components/checkbox-group/) oder [Radio-Button-Group](/de/design-system/lyne/components/radio-button-group/) eingesetzt.
* Pro Panel gibt es genau eine Aktion. Sie muss sich klar von der Auswahl der Option unterscheiden.
* Die Aktion soll verständlich beschriftet sein. Bei einem Button nur mit Icon braucht es eine Beschriftung für Screenreader.
* Sollen zusätzliche Inhalte aufklappen, wird das Selection-Action-Panel mit dem [Selection-Expansion-Panel](/de/design-system/lyne/components/selection-expansion-panel/) kombiniert.
