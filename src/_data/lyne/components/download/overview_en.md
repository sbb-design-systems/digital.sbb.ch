
## What does the component do?
A download displays a document for downloading, e.g. a PDF. The whole area is a link. Title, file type, size and modification date help users judge what they will get.

## When should the component be used?
* To offer documents such as reports, forms or fact sheets for download.
* To list several documents in a consistent way.

## Rules.
* The title describes the content of the document, not the file name.
* File type and size should always be shown, the modification date if it is relevant to users.
* Documents that are not accessible must be marked as such.
* For links to web pages, use a link or a card, not a download.
