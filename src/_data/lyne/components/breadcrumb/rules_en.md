## Rules.
* The breadcrumb group always starts at the home page and shows the complete path to the current page.
* The individual levels are labelled clearly and understandably.
* It shows no more than 5–7 levels. If there is not enough space, only the first and the last level are shown with "…" in between. Clicking it shows all levels again.
* The first level (home page) is displayed with an icon only.
* The breadcrumb group needs an `aria-label` describing its context. The current page is automatically marked for screen readers.
