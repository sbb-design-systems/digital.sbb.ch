## Rules.
* The link texts are descriptive and meaningful.
* The links are organised by topic.
* The list contains only a few links so that it stays clear.
* The list is vertical by default. From a selectable breakpoint, it can be displayed horizontally. When horizontal, the title is not displayed.
* For jumps within the current page, use the [link list anchor](/en/design-system/lyne/components/link-list-anchor/).
