
## What does the component do?
A toggle check switches between two states, e.g. "on" and "off". It behaves like a [checkbox](/en/design-system/lyne/components/checkbox/).

## When should the component be used?
* To switch a function or setting on or off that takes effect immediately.

## Rules.
* For selections in forms that only apply after submission, use the checkbox.
* The toggle check needs a label. Without a visible label, set an `aria-label`.
* Do not place further interactive elements in the label.
