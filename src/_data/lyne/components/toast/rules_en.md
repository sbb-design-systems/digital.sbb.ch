## Rules.
* The text is short and concise.
* Only one toast can be shown at a time. A new toast replaces the previous one.
* Important information, e.g. errors, does not belong in a toast alone, as it can disappear and is burdensome for screen reader users.
* Actions in a toast are hard to reach. Also offer the action elsewhere.
* Do not set a timeout for toasts with an action. Otherwise choose a sensible timeout or allow manual closing.
* Within an application, toasts always appear in the same position.
