
## Was macht die Komponente?
Sie gewährleistet das Layout bei einer Gruppe von Checkboxen.

## Wann soll die Komponente eingesetzt werden?
* Nur in Kombination mit der Checkbox-Komponente.

## Regeln.
* Eine Checkbox-Group fasst nur Checkboxen zusammen, die zur selben Frage gehören. Die Gruppe braucht eine verständliche Beschriftung.
* Die Checkboxen werden untereinander angeordnet. Nebeneinander nur bei wenigen, kurzen Optionen.
* Alle Checkboxen einer Gruppe haben dieselbe Grösse.
* Ist eine Auswahl erforderlich, wird bei fehlender Auswahl eine Fehlermeldung zur ganzen Gruppe angezeigt.
