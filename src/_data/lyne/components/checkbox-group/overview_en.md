
## What does the component do?
It provides the layout for a group of checkboxes.

## When should the component be used?
* Only in combination with the checkbox component.
## Rules.
* A checkbox group only combines checkboxes that belong to the same question. The group needs a clear label.
* The checkboxes are arranged one below the other. Side by side only for a few short options.
* All checkboxes in a group have the same size.
* If a selection is required and none is made, an error message is shown for the whole group.
