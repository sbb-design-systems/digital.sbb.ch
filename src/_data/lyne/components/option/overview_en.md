
## What does the component do?
The option is a selectable entry in an [autocomplete](/en/design-system/lyne/components/autocomplete/) or [select](/en/design-system/lyne/components/select/) component. Options can be grouped with an optgroup. In autocomplete, a hint (option hint) can be shown additionally.

## When should the component be used?
* Only within the autocomplete or select component.
