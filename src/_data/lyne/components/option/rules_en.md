## Rules.
* Each option has a short, clear label and is clearly distinguishable from the others.
* Related options are grouped with an optgroup. If the group is disabled, all its options are disabled.
* An icon is optional.
* When searching in autocomplete, the matching text is highlighted in bold.
* The option hint (e.g. "No results") is only possible in autocomplete. Screen readers read it only as plain text; mark it as a live region if needed.
