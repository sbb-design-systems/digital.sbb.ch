
## What does the component do?
The map container is a layout for pages with a map. It divides the page into a sidebar for content and an area for the map. On large screens both are shown side by side. On small screens the map stays at the top and the content scrolls over it.

## When should the component be used?
* For pages that show a map together with content or navigation, e.g. a disruption map.

## Rules.
* The map container fills the page below the header. Use only one map container per page.
* The sidebar contains the content that belongs to the map, e.g. lists, filters or details about a location.
* Content and map should relate to each other: what is selected in the sidebar should be recognisable on the map.
