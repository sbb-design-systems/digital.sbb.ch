
## Was macht die Komponente?
Ein Date-Input ist ein Eingabefeld, in das Nutzende ein Datum direkt eintippen. Die Eingabe wird im lokalen Datumsformat dargestellt und auf Gültigkeit geprüft.

Im Unterschied zum Date-Picker bietet der Date-Input keine Kalender-Ansicht.

## Wann soll die Komponente eingesetzt werden?
* Wenn Nutzende das Datum kennen und es schneller eintippen als im Kalender suchen, z.B. das Geburtsdatum.
* Wenn das Datum weit in der Vergangenheit oder Zukunft liegt.
* Wenn wenig Platz zur Verfügung steht.

## Regeln.
* Der Date-Input steht immer in einem Form-Field mit verständlichem Label.
* Wo sinnvoll, soll ein Standardwert gesetzt sein, z.B. das heutige Datum.
* Ist nur ein bestimmter Zeitraum zulässig, sollen ein frühestes und ein spätestes Datum festgelegt werden.
* Bei einer ungültigen Eingabe (z.B. ein Datum ausserhalb des zulässigen Zeitraums) soll eine klare und verständliche Fehlermeldung angezeigt werden.
