
## What does the component do?
A date input is an input field in which users type a date directly. The entry is displayed in the local date format and checked for validity.

Unlike the date picker, the date input does not offer a calendar view.

## When should the component be used?
* When users know the date and can type it faster than finding it in a calendar, e.g. a date of birth.
* When the date lies far in the past or future.
* When space is limited.

## Rules.
* The date input is always placed in a form field with a clear label.
* Where useful, a default value should be set, e.g. today's date.
* If only a certain period is permitted, an earliest and a latest date should be defined.
* Invalid entries (e.g. a date outside the permitted period) should be displayed with a clear and understandable error message.
