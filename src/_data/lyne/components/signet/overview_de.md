
## Was macht die Komponente?
Die Komponente zeigt das SBB-Signet an und stellt Seitenverhältnis und Schutzraum sicher. Sie ist Bestandteil des [Logos](/de/design-system/lyne/components/logo/).

## Wann soll die Komponente eingesetzt werden?
* Wenn nur das Signet ohne Schriftzug benötigt wird, z.B. im Header mit kleiner Grösse.
* Für das vollständige Logo wird die Logo-Komponente verwendet.

## Regeln.
* Das Signet darf nicht verändert werden.
* Die Grösse (Höhe oder Breite) wird am Element festgelegt. Der Schutzraum wird über die Variante bestimmt (ideal, minimal, panel, none).
* Setze eine Beschriftung für Screenreader, wenn das Signet als eigenständiges Element erscheint.
