
## What does the component do?
The component displays the SBB signet and ensures its aspect ratio and protective room. It is part of the [logo](/en/design-system/lyne/components/logo/).

## When should the component be used?
* When only the signet without the wordmark is required, e.g. in the header at a small size.
* For the complete logo, use the logo component.

## Rules.
* The signet must not be changed.
* The size (height or width) is set on the element. The protective room is determined by the variant (ideal, minimal, panel, none).
* Provide a label for screen readers if the signet appears as a standalone element.
