
## What does the component do?
A checkbox is a selection field. Users use it to select or deselect one or more options.

## When should the component be used?
* To select several independent options.
* To offer a yes/no choice, for example a consent such as a newsletter subscription.
* To control a group of dependent options with a parent checkbox. If only some options are selected, it shows the "partial" state.

## Rules.
* Each checkbox is clearly labelled and names the option unambiguously.
* Related checkboxes are grouped. A group does not contain too many options (maximum 5–7).
* The label does not contain other interactive elements.
* Without visible text, the checkbox needs an `aria-label`.
