## Rules.
* A button is clearly labelled and describes a specific action.
* There is only one primary button per area. Further actions are secondary buttons or [links](/en/design-system/lyne/components/link/).
* A button has a label, an icon or both. An icon-only button needs a label for screen readers.
* While an action is in progress, a button can be set to the loading state.
* On dark backgrounds, the negative variant is used.
* If an action is unavailable and the reason needs to be explained, an interactively disabled button (`disabled-interactive`) is used so that it remains focusable.
