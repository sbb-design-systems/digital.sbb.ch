## Regeln.
* Die Optionen sollen eindeutig beschriftet und leicht verständlich sein.
* Verwende eine sinnvolle Standardauswahl, falls dies für den Anwendungsfall relevant ist. Ohne Standardwert wird ein Platzhalter angezeigt.
* Das Select wird in der Regel innerhalb eines [Form-Fields](/de/design-system/lyne/components/form-field/) eingesetzt (Label, Hilfetext, Fehlermeldung).
* Bei Mehrfachauswahl (`multiple`) erscheint vor jeder Option eine Checkbox.
