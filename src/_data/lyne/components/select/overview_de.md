
## Was macht die Komponente?
Ein Select ermöglicht es Nutzenden, eine oder mehrere Optionen aus einer Liste zu wählen.

## Wann soll die Komponente eingesetzt werden?
* Wenn Nutzende aus einer umfangreichen Liste von Optionen wählen sollen, die zu gross für [Radio-Buttons](/de/design-system/lyne/components/radio-button/) oder [Checkboxen](/de/design-system/lyne/components/checkbox/) ist.
* Um Platz auf der Benutzeroberfläche zu sparen, indem die Optionen in einem Dropdown verborgen werden.
* Bei sehr langen Listen, in denen Nutzende suchen oder filtern müssen, ist stattdessen das [Autocomplete](/de/design-system/lyne/components/autocomplete/) geeigneter.
