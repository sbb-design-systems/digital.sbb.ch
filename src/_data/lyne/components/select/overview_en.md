
## What does the component do?
A select allows users to choose one or more options from a list.

## When should the component be used?
* When users should choose from an extensive list of options that is too large for [radio buttons](/en/design-system/lyne/components/radio-button/) or [checkboxes](/en/design-system/lyne/components/checkbox/).
* To save space on the user interface by hiding the options in a dropdown.
* For very long lists where users need to search or filter, the [autocomplete](/en/design-system/lyne/components/autocomplete/) is more suitable.

## Rules.
* The options should be clearly labelled and easy to understand.
* Use a useful default selection if this is relevant for the use case. Without a default value, a placeholder is shown.
* The select is usually used within a [form field](/en/design-system/lyne/components/form-field/) (label, help text, error message).
* With multiple selection (`multiple`), a checkbox is shown in front of each option.
