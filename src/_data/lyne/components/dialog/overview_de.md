
## Was macht die Komponente?
Ein Dialog ist ein [Overlay](/de/design-system/lyne/components/overlay/), das über dem Hauptinhalt der Seite liegt und diesen sperrt. Er zeigt eine wichtige Information oder eine fokussierte Interaktion, bis Nutzende die Aktion abschliessen oder den Dialog schliessen.

## Wann soll die Komponente eingesetzt werden?
* Um wichtige Informationen oder Bestätigungen zu übermitteln.
* Um Nutzende zu einer Handlung aufzufordern, bevor sie auf der Seite weitermachen.
* Um komplexe Formulare oder Inhalte anzuzeigen, die nicht in die Hauptseite passen.

## Regeln.
* Ein Dialog hat immer einen Titel und Inhalt. Er ist so reduziert wie möglich und beschränkt sich auf eine Aufgabe, eine Information oder ein Formular.
* Im Footer stehen höchstens zwei Aktionen, [Buttons](/de/design-system/lyne/components/button/) oder Block-Links.
* Ein Dialog lässt sich immer schliessen: mit der ESC-Taste, mit einer Aktion oder mit einem Klick auf den Hintergrund. Der Klick auf den Hintergrund kann deaktiviert werden.
* Bei komplexem Inhalt gehört ein Schliessen-Button dazu. Er ist zugleich ein zweiter Ausgang und liefert den Startfokus.
* Der Fokus startet im Dialog und kehrt beim Schliessen zum auslösenden Element zurück.
