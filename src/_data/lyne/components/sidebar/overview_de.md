## Was macht die Komponente?
Die Sidebar zeigt Inhalte am linken oder rechten Rand der Anwendung an. Sie ist für Navigation gedacht, kann aber beliebigen Inhalt enthalten, z.B. Filter.

## Wann soll die Komponente eingesetzt werden?
* Wenn eine Anwendung eine permanente oder leicht zugängliche Navigation neben dem Hauptinhalt benötigt.
* Wenn zusätzliche Funktionen oder Filter neben dem Hauptinhalt verfügbar sein sollen.

## Regeln.
* Die Sidebar wird für Vollbild-Anwendungen eingesetzt. Pro Seite (links/rechts) ist nur eine Sidebar erlaubt.
* Im Modus «Side» steht die Sidebar neben dem Inhalt. Im Modus «Over» deckt ein Backdrop den Inhalt ab. Bei wenig Platz wechselt «Side» automatisch zu «Over».
* Es darf höchstens eine Sidebar im Modus «Over» gleichzeitig geöffnet sein.
* Biete immer einen Button zum Öffnen und Schliessen an, idealerweise im [Header](/de/design-system/lyne/components/header/). Sonst können Nutzende die Sidebar bei wenig Platz nicht öffnen.
* Gib der Sidebar einen Titel und bei Bedarf einen Schliessen-Button.
* Wird die Sidebar mit der [Icon-Sidebar](/de/design-system/lyne/components/icon-sidebar/) kombiniert, verwendet eine der beiden die Farbvariante «Milk». So lassen sich die Komponenten visuell unterscheiden.
