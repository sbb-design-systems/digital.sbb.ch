
## What does the component do?
It provides the layout for a group of radio buttons.

## When should the component be used?
* Only in combination with the radio button component.
## Rules.
* A radio button group only combines radio buttons that belong to the same question. The group needs a clear label.
* The radio buttons are arranged one below the other. Side by side only for a few short options.
* All radio buttons in a group have the same size.
* If a selection is required and none is made, an error message is shown for the whole group.
