
## Was macht die Komponente?
Sie gewährleistet das Layout bei einer Gruppe von Radiobuttons.

## Wann soll die Komponente eingesetzt werden?
* Nur in Kombination mit der Radiobutton-Komponente.
## Regeln.
* Eine Radio-Button-Group fasst nur Radiobuttons zusammen, die zur selben Frage gehören. Die Gruppe braucht eine verständliche Beschriftung.
* Die Radiobuttons werden untereinander angeordnet. Nebeneinander nur bei wenigen, kurzen Optionen.
* Alle Radiobuttons einer Gruppe haben dieselbe Grösse.
* Ist eine Auswahl erforderlich, wird bei fehlender Auswahl eine Fehlermeldung zur ganzen Gruppe angezeigt.
