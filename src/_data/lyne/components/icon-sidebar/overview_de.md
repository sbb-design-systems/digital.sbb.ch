
## Was macht die Komponente?
Die Icon-Sidebar ist eine vertikale Navigationsleiste für Anwendungen. Sie ermöglicht den schnellen Wechsel zwischen Bereichen oder Funktionen. Sie kann Links oder Buttons enthalten. Im Overlay-Modus wird der Inhalt dahinter mit einem Backdrop abgedeckt.

## Wann soll die Komponente eingesetzt werden?
* Wenn eine Anwendung eine permanente oder leicht zugängliche Navigation benötigt.
* Wenn Nutzende schnell zwischen mehreren Hauptbereichen wechseln müssen.

## Regeln.
* Die Icon-Sidebar kann mit der [Sidebar](/de/design-system/lyne/components/sidebar/) kombiniert werden. Dann verwendet eine der beiden die Farbvariante «Milk», damit sie sich visuell unterscheiden.
* Die Icon-Sidebar steht links oder rechts. Zwei Icon-Sidebars gleichzeitig werden nicht empfohlen.
* Links und Buttons nur mit Icon haben immer eine Beschriftung für Screenreader und zeigen beim Hover einen Tooltip mit der Beschriftung.
* Der aktive Eintrag wird markiert und für Screenreader als aktuelle Seite ausgezeichnet.
* In Kombination mit dem [Header](/de/design-system/lyne/components/header/) muss dessen `scroll-origin` auf den scrollenden Inhaltsbereich zeigen.
