
## What does the component do?
The icon [sidebar](/en/design-system/lyne/components/sidebar/) is a vertical navigation bar for applications. It enables quick switching between areas or functions. It can contain links or buttons. In overlay mode, the content behind it is covered by a backdrop.

## When should the component be used?
* When an application needs permanent or easily accessible navigation.
* When users need to switch quickly between several main areas.

## Rules.
* The icon sidebar can be combined with the sidebar. In that case, one of the two uses the "Milk" colour variant so that they are visually distinct.
* The icon sidebar is placed on the left or right. Two icon sidebars at the same time are not recommended.
* Links and buttons with an icon only always have a label for screen readers and show a tooltip with the label on hover.
* The active item is highlighted and announced to screen readers as the current page.
* In combination with the [header](/en/design-system/lyne/components/header/), its `scroll-origin` must point to the scrolling content area.
