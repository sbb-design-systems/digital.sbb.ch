
## Was macht die Komponente?
Das Teaser-Panel zeigt einen kurzen Text in einer roten, trapezförmigen Fläche an. Es ist der Baustein, mit dem z.B. der [Teaser-Hero](/de/design-system/lyne/components/teaser-hero/) seinen Text über einem Bild darstellt.

## Wann soll die Komponente eingesetzt werden?
* Wenn ein Bild oder eine Fläche mit einer kurzen, prägnanten Botschaft ergänzt werden soll.
* Wenn eigene Teaser-Layouts gebaut werden, die der Teaser-Hero nicht abdeckt.

## Regeln.
* Der Text im Panel ist kurz, z.B. ein Titel oder ein Satz.
* Das Panel ist selbst nicht interaktiv. Soll es klickbar sein, wird es mit einer interaktiven Komponente (z.B. [Button](/de/design-system/lyne/components/button/) oder [Link](/de/design-system/lyne/components/link/)) umschlossen.
* Für einen klassischen Bild-Teaser mit Link soll der Teaser-Hero verwendet werden.
